# AI Resume Analyzer & Correction Tool

A Python-based resume analyzer that identifies skills in a resume and compares them with job requirements.

## Features
- Resume skill detection
- Job description skill matching
- Missing skill identification
- Resume analysis using Python

## Technologies Used
- Python
- Jupyter Notebook
- GitHub

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the Python file:

python resume_analyzer.py
